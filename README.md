## Project Overview

Planet Explorer is a collaborative capstone project that recreates the provided design mockup as a fully functional web application.

The application allows users to explore information about planets in our solar system through a clean, responsive interface with both **Light Mode** and **Dark Mode** support.

This project demonstrates our understanding of:

- HTML fundamentals
- CSS styling and responsive layouts
- JavaScript functionality
- Fetch API
- Git collaboration
- Pull Request workflows
- Web deployment

---

## Features

The application is designed to include:

- Planet search functionality
- Light and Dark mode toggle
- Fully responsive design
- Planet temperature display
- Moon count
- Distance from the Sun
- Gravity information
- Diameter
- Mass
- Orbital period
- Planet description
- Planet images
- Loading and error handling for API requests

##  Getting Started

### Prerequisites

Before running the project, install:

- Git
- Visual Studio Code (recommended)
- A modern web browser

### Clone the Repository

```bash
git clone https://github.com/Ematefaith0/group-19.git
cd group-19
```

### Run Locally

Since this project uses **HTML, CSS, and JavaScript**, you can run it by:

1. Opening the project folder in **Visual Studio Code**.
2. Opening `index.html` in your browser.

For the best experience, use the **Live Server** extension.

## Git Workflow

Our team follows a branch-based workflow.

### 1. Update Main

```bash
git switch main
git pull origin main
```

### 2. Create a Feature Branch

```bash
git switch -c feature/your-task
```

### 3. Commit Your Changes

```bash
git add .
git commit -m "Add your feature"
```

### 4. Push to GitHub

```bash
git push origin feature/your-task
```

### 5. Open a Pull Request

- Open a PR into `main`.
- Another team member reviews it.
- The PR author does **not** merge their own PR.
- Merge after approval.
